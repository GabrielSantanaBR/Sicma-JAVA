abre caminhos.

O que é matemática olímpica?+

É uma maneira de estudar matemática com foco em raciocínio, criatividade e resolução de problemas. Ela valoriza as ideias por trás de cada solução.

Preciso ser medalhista para começar?+

Não. Os exercícios demonstrativos deste site são abertos, com diferentes níveis. Para informações sobre participação presencial no projeto SICMA, procure seus canais institucionais.

O treino salva meu progresso?+

Sim, exclusivamente no armazenamento do seu navegador. Não enviamos respostas, nomes ou dados escolares a um servidor.

Este é o site original do SICMA?+

Esta é uma recriação independente do portal, baseada em referências públicas. Algumas informações e recursos do site anterior não estavam acessíveis; não há inscrições oficiais por aqui.
